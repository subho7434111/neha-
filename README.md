## 🎶 Gaan / Music Kaise Change Karein? (3 Simple Options):

### Option 1: Top Bar Ke "🎶 Song" Menu Se (Direct Web Page Par)
1. Page ke top-right corner me **"🎶 Song"** button par tap karein.
2. 3 built-in melodies me se koi bhi select karein:
   - 🎵 **Classic Music Box**: Sweet chime tune.
   - 🎹 **Lofi Dreamy Birthday**: Calm, acoustic & aesthetic vibes.
   - 🎉 **Celebration Chimes**: Fast, joyful & energetic.

### Option 2: Neha Ka Favorite Gaana (MP3) Upload Karein
1. Top bar ke **"🎶 Song"** button par tap karein.
2. **"📂 Upload Any Song (MP3)"** par tap karke apne phone ya PC se Neha ka favorite song, Hindi/Bengali romantic/fun track, ya apna voice note select karein!
3. Woh song turant play hona shuru ho jayega.

### Option 3: Folder Me `song.mp3` Rakh Dein
- Agar aap chahein ki web page open hote hi directly koi specific gaana baje:
  - Apne MP3 song ka naam **`song.mp3`** rakhein.
  - Aur use is folder me daal dein:
    📂 `C:\Users\rayhe\.gemini\antigravity\scratch\neha-birthday-surprise\`
  - Web app automatically `song.mp3` ko detect karke play karega!
